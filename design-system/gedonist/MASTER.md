# MASTER: «Место гедониста» — мир «Градусник»

Идея: гость идёт с мороза в тепло. Каждая зона сайта имеет свою температуру, цвет и свет. Палитра взята из самой базы: тёмно-зелёная обшивка дома, терракотовый тент, красный ковёр, дерево ферм, шалфейные стены.

## Шрифты (лежат в docs/vendor/fonts, правила — в docs/vendor/fonts/fonts.css)
- Prata 400 — заголовки. H1 6rem / 0.95 (моб. 3.25rem), H2 3rem / 1.05 (моб. 2rem), H3 2.25rem / 1.1 (моб. 1.625rem). letter-spacing −0.01em. text-wrap: balance.
- Golos Text 400/500 — текст. 1.0625rem / 1.55; мелкий 0.875rem / 1.45. Длина строки ≤ 34rem.
- Sofia Sans Extra Condensed 600 — только числа: температура, цены, шкала. font-variant-numeric: tabular-nums. Температура на шкале 5rem / 0.9; цены в счёте 1.5rem.
Запрещено: Inter, Manrope, Montserrat, системные шрифты в заголовках, градиентный текст, надзаголовки-кикеры, нумерация 01/02/03.

## Форма
- Радиусы: кнопки 4px, фото 6px, счёт 2px. Никаких «пилюль» и одинаковых карточек.
- Тени: только у счёта (0 14px 40px −18px rgba(0,0,0,.55)).
- Кнопка главная: фон --carpet, текст --cream, 1rem/1 Golos 500, padding 1rem 1.5rem; hover — фон --carpet-d; active — translateY(1px); focus-visible — outline 2px --sail, offset 3px.
- Ссылки: подчёркивание 1px, text-underline-offset .22em; hover — цвет --sail (на ночи) или --carpet (на светлом).
- ::selection — фон --carpet, цвет --cream. Полоса прокрутки тонкая: бегунок --sail, дорожка --night.
- Русская типографика: «ёлочки», тире «—», минус «−» (U+2212) в температурах, неразрывный пробел после предлогов и перед ₽ и °.

## Движение
- Одна авторская сцена: оттаивание стекла в Hero. Вторая большая — облёт макета по прокрутке. Остальное сдержанно.
- Кривые: power3.out / power4.out для появления, power3.inOut для перелёта. Без пружин и отскоков.
- prefers-reduced-motion: без прелоадера и облёта, стекло оттаяно статично, макет показывается постером.
